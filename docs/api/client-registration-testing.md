# Тестирование API регистрации клиента

## Подготовка к тестированию

1. Убедитесь, что API сервер запущен и доступен по адресу `https://dockernel-api.dvl.to/`
2. Сделайте скрипт исполняемым:
   ```bash
   chmod +x scripts/test-client-registration.sh
   ```

## Запуск тестов

Для запуска всех тестов выполните:
```bash
./scripts/test-client-registration.sh
```

## Описание тестов

Скрипт выполняет три тестовых сценария:

1. **Успешная регистрация**
   - Отправляет корректные данные
   - Ожидает код ответа 201
   - Проверяет структуру ответа

2. **Ошибка валидации**
   - Отправляет некорректные данные (слишком короткие значения)
   - Ожидает код ответа 400
   - Проверяет наличие сообщений об ошибках

3. **Отсутствие обязательных полей**
   - Отправляет неполные данные
   - Ожидает код ответа 400
   - Проверяет наличие сообщений об отсутствующих полях

## Интерпретация результатов

- 🟢 Зеленый текст означает успешное выполнение теста
- 🔴 Красный текст означает ошибку в тесте
- 🟡 Желтый текст используется для заголовков и информационных сообщений

## Требования

- curl
- bash
- python (для форматирования JSON-ответов)
